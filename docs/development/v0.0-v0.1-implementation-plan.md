## Known limitations / open items

- Desktop UI blocks overview/query commands while an import runs (the
  workspace moves into the job); v0.1 lifts this with a shared handle.
- OTLP network receivers retain envelope hashes, not raw bytes (spike
  limitation; ADR-0009).
- Fixed WebView2 runtime is not downloaded/bundled in this environment; the
  packaging script supports `-WebView2FixedDir` and the manifest records
  which flavor was built.
- v0.1 scope (workspace lifecycle UI, text/multiline/UTF-16 parsers,
  archives, rotation families, full profile set, import wizard, 5M
  benchmark) not started.
