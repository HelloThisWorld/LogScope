## v0.0 spike inventory relevant to v0.7 (verified this session)

  receivers (ADR-0009): axum HTTP (protobuf + JSON) and tonic gRPC for
  all three signals; binds strictly 127.0.0.1; **disabled by default**
  (both ports `None`); bounded body (8 MiB default → 413) and bounded

## Preflight decision (per milestone rules)

The v0.7 milestone rules distinguish narrow gaps ("fix narrow
regressions or small missing prerequisites … do not redesign completed
… foundations") from major prerequisites ("If a major prerequisite such
as recoverable publication ordering, exact query revisions, shared
Resource/Scope identity, safe workspace locking, lossless span storage,
bounded background execution, or canonical normalizer reuse is absent,
**stop before enabling a production receiver or watcher through an
incompatible parallel system**"), and additionally forbid silently
reimplementing v0.0 through v0.6.

The gaps found are not narrow regressions. Directly from the stop
rule's named list: **safe workspace locking is absent** (P16),
**canonical normalizer reuse is absent for metrics** (P8), **recoverable
publication ordering for incremental checkpoints is absent** (P14),
**exact query revisions for append-capable active snapshots are absent**
(P6), and **lossless span storage at the production typed-column
contract is absent** (P9 caveat). Around them sit three unimplemented
milestones plus six-plus unstarted v0.3 work packages:

| Missing capability | Milestone debt | v0.7 work it blocks |
|---|---|---|
| Production metric canonicalizer, static importer, Metric Query Definition, Metrics Explorer | all of v0.6 | WP2 shared normalization for metrics; WP11 "newly published metrics visible through the existing Metrics Explorer"; live-metric latency targets; gates 37/62–63 |
| Agent Query Protocol v1alpha1 (registry, envelopes, capability discovery, cursors, budgets, disclosure profiles, tokens, audit, CLI, loopback HTTP gateway) | all of v0.5 | WP11 Agent integration (revision-pinned cursors, additive capability metadata); gates 70–72; cross-surface conformance |

| Shared disclosure/redaction projection | v0.3 W6 | WP10 diagnostics copy/export; WP11 report/bundle redaction of paths/attributes/endpoints; gate 67/69 |
| Report generation + exact report revisions | v0.3 W5 | WP11 fixed-revision reports over live data; e2e gate 88 |

Of v0.7's work packages, WP11 (explorer/case/Agent integration) has
**no baseline to extend at all**; WP10's diagnostics disclosure and
WP9's protected-reference analysis depend on contracts v0.3 W5–W7
define; and while WP1–WP8 (schemas, decode path, watcher, rotation,

evidence/report/bundle/disclosure/Agent/metric contracts that the
remediation chain will define — exactly the incompatible parallel

(durable acceptance and acknowledgement). The correct action is to
stop, keep the repository valid and green, record this preflight, and
extend the remediation chain.

watcher/span-storage/segment/retention/UI/integration code was added;
