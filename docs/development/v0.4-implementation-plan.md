## Preflight decision (per milestone rules)

The milestone rules distinguish narrow gaps ("fix … when clearly
required and do not redesign completed foundations") from major
prerequisites ("if … consistent report snapshots … is absent, **stop
before building analysis results that cannot be reproduced**").

The gaps found are not narrow regressions. They are six-plus unstarted
v0.3 work packages:

| Missing capability | v0.3 package | v0.4 work it blocks |
|---|---|---|
| Investigation + evidence UX (pin dialogs, evidence panel, Tauri case commands) | W3, W4 | WP7 analysis workspace UX; gate 30 (pin via real UI flows); e2e tests 1–6 |
| Report generation (consistent snapshot, deterministic MD/HTML) | W5 | WP6 report integration; gates 32–33; e2e test 7 |
| Shared disclosure/redaction projection + preview | W6 | WP6 redaction equivalence for templates/examples/keys; gate 33 |
| Portable case bundle (planner/writer/hostile import) | W7 | WP6 bundle reproduction states; gates 34–35; e2e test 8 |
| 5M-workspace + evidence benchmarks, recovery passes | W8 | WP8 baselines the v0.4 benchmarks extend; gates 36–37 |
| v0.3 test sweep + acceptance matrix + 0.3.0 release | W9, W-R | gate 1's "actual v0.3 acceptance report"; gate 2's "existing valid v0.3 workspace" as a released, frozen schema |
| Graphical setup extractor + byte-equivalence | W-R (inherited gate-19 debt) | gate 41 (both artifacts from one payload) |

Building v0.4's analysis engine now would force one of two outcomes the
prompt forbids: silently implementing most of v0.3 inside this
milestone, or shipping analysis runs whose evidence cannot be captured
into reports/bundles — i.e., results without the reproduction and
disclosure guarantees that define the milestone. The correct action is
to stop, keep the repository valid and green, record this preflight,
and hand off a remediation path.

What was deliberately **not** done: no analysis schema/migration was
added, no v0.4 dependency was introduced, no version string changed, no
v0.3 code was rewritten. The only change in this session is this
document.
