## Query language v1 — decision table

Grammar version: **1** (stored with saved searches; parser rejects newer).

| Decision | Choice |
|---|---|
| Precedence | `()` > `NOT` > `AND` > `OR`; adjacency = implicit `AND` |
| `:` vs `=` | exact aliases for typed equality (documented; no text-vs-term distinction) |
| Operators | `:` `=` `!=` `>` `>=` `<` `<=`; `field:*` exists; `NOT field:*` missing |
| Field group | `f:(A OR B)` expands to `(f:A OR f:B)`; groups allow OR/AND/NOT of values |
| Free text | token match on `display_message`, case-insensitive (Unicode simple fold), diacritics NOT folded; phrase = consecutive tokens |
| Wildcard | `*` multi-char, `?` single-char, in values only; leading wildcard allowed but flagged as expensive; compiled to RE2 via one escaper |
| Regex | `field:/pat/` + optional `i` flag; linear-time engines only (validated by Rust `regex` with size_limit, executed by DuckDB RE2); backreferences/lookaround rejected at validation |
| Timestamps | RFC3339 literals; compiled to UTC nanos; half-open `[start, end)` everywhere |
| Severity | `severity` = canonical level; equality matches the OTLP band (ERROR = 17..=20) or, when number is absent, case-insensitive text; ordering comparisons use `severity_number` |
| Field names | dotted paths; resolution order: canonical field → alias → dataset attribute; `attr.` prefix forces attribute namespace; unknown field = semantic error listing near-misses |
| Aliases | via catalog only: `level`,`log.level`→severity; `msg`,`body`→message; `@timestamp`,`time`→timestamp; `trace.id`→trace_id; `span.id`→span_id; ambiguity (alias collides with a real attribute key) = error demanding the explicit form |
| Types | attr predicates type-checked against catalog (str/int/double/bool); invalid coercion = semantic error with field, expected type, value, span; int↔double comparisons allowed (numeric class) |
| Null/missing | `field:*` = present AND non-Empty; missing = key absent or Empty; empty string is a present value, matchable with `field:""` |
| Case | field names case-sensitive; severity values case-insensitive; text terms case-insensitive; other value comparisons exact |
| Limits | query ≤ 4096 chars, ≤ 512 tokens, AST depth ≤ 32, ≤ 128 boolean clauses, wildcard value ≤ 128 chars, regex ≤ 512 chars + 256 KiB compiled size, execution budget default 15 s, page ≤ 1000 rows |
| Serialization | canonical JSON AST (BTree ordering) + `qry-<hex>` fingerprint via existing stable_id |
| Untimestamped records | included in all-data queries; excluded from bounded intervals with an explicit omitted count; never given invented timestamps |
| Sort | `event_time DESC NULLS LAST, record_id DESC, dataset_id DESC` (total order; keyset cursor over the triple) |

Roadmap example `service.name:workflow AND severity:(ERROR OR WARN) AND
"timed out" AND NOT retry.count:0` parses to: attr-or-alias equality AND
severity band group AND phrase AND NOT numeric attr equality.

Authoritative parser: Rust only. The editor gets tokens/diagnostics from a
debounced backend `lex_query`/`validate_query` command — there is no
second grammar in TypeScript, so no conformance-corpus drift risk.

## Schema and index migrations

Migration `0002_explorer` (one transaction, forward-only):
- `field_stats` (dataset_id, field_kind canonical|attr, name, type, count,
  missing, distinct_est, distinct_is_exact, examples_json, built_at,
  catalog_version, segment_count_at_build) — rebuildable derived catalog;
- `index_state` (kind e.g. `fts`, version, dataset_id, status
  pending|building|ready|failed, updated_at, detail_json);
- `saved_searches` (id, name, query_text, language_version, fingerprint,
  dataset_selection_json, time_strategy_json, created/updated);
- `column_sets` (id, name, columns_json ordered canonical identities,
  is_default);
- `recent_searches` (id, query_text, language_version, fingerprint,
  dataset_selection_json, time_strategy_json, last_run_at, run_count;
  bounded to 50, deduped by fingerprint+selection);
- `export_jobs` (id, job_id, format, destination, query_fingerprint,
  query_text, row_limit, byte_limit, rows_written, bytes_written,
  truncated, status, created/finished);
- seeds `index_state` rows for existing datasets: FTS v1 → `pending`
  rebuild to v2 tokenizer (`unicode61 remove_diacritics 0`), catalog →
  `pending`.

FTS v2 rebuild + catalog build run as cancellable jobs after migration;
until ready, text queries use the documented bounded regex fallback (same
semantics, slower) and suggestions are absent — never silently wrong.
Parquet storage schema is UNCHANGED (v1), so no data rewrite occurs.

## UI state and interaction model

Views: `home` (existing workspace/import shell, restyled header) and
`explorer`. Explorer state:
- selection: dataset ids (default all published log datasets);
- query: text, diagnostics, tokens (backend-provided), language version;
- time strategy: `all` | `absolute{start,end}` | `relative-to-latest{dur}`
  + resolved interval echoed from every result;
- execution: request_id (monotonic), phase idle|running|done|cancelled|
  timed-out|failed, duration, truncation/approx flags; stale responses
  (request_id < latest) are dropped by the client and cancelled server-side;
- results: cursor pages cached in a window (≤ 3 pages either side),
  virtualized rows (fixed row height, overscan 10);
- histogram: bins + brush selection → writes an absolute time strategy;
- facets: selected fields (bounded), value toggles append/remove
  predicates through the authoritative serializer (visible in the editor);
- detail: selected record (full row fetch by id), tabs canonical/attrs/
  resource+scope/provenance/raw context;
- saved state: searches, column sets, recents (SQLite via commands).
Run is explicit (button / Ctrl+Enter); validation is debounced 150 ms;
Escape or Cancel button interrupts. Import runs remain exclusive (v0.0
model): Explorer shows a blocking "import running" state; documented.

## Performance and security risks

| Risk | Mitigation |
|---|---|
| SQL injection via values/fields | values only as bound params; field identifiers only from the trusted catalog through one quoting path; hostile-input tests |
| Regex/wildcard DoS | linear engines only, size/length caps, execution budget + interrupt watchdog |
| FTS/fallback divergence | v2 tokenizer chosen to match fallback semantics; equivalence tests on a Unicode corpus; auto-fallback when FTS candidates overflow the bound, so results stay exact |
| Large results in webview | keyset pages ≤ 1000 rows, virtualization, page-window eviction |
| Stale responses | monotonic request ids client+server; superseded queries cancelled |
| Export overwrite/partial files | temp file + atomic rename, no silent overwrite, truncation flagged, cleanup on cancel/failure |
| CSV formula injection | documented guard: risky leading chars prefixed with `'` (on by default) |
| Untrusted log text in UI | React text nodes only (no dangerouslySetInnerHTML), field-size bounds + explicit expansion, no auto-links |
| Attr catalog scan cost | per-dataset one-shot job at publish/backfill, DuckDB aggregate over `json_keys`, budget + cancel |
| DuckDB param limits with FTS id sets | ids via temp table + Appender, bounded, then dropped |
