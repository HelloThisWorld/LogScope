# LogScope v0.9 Implementation Plan — Preflight Record (BLOCKED)

Updated: 2026-08-01 (preflight session)
Branch: `feature/logscope-v0.9` (from `origin/main` @ `e5dfd0e`, the
PR #9 merge of the v0.8 preflight record)

v0.9 goal: Compatibility Ecosystem and Open-Source Extension Kit —
locally installable declarative extension packs (registry manifest,
Import Profiles, bundle recipes, dashboard/report templates) validated
and atomically published into one authoritative registry; a closed,
typed, deterministic profile DSL and compiler; built-in Tier B profiles
for Java/.NET/Node/Python/Go/logfmt and container/system envelopes
(Docker `json-file`, Kubernetes CRI, journald JSON export, RFC
5424/3164); pinned OpenTelemetry Collector bridge recipes; a public
compatibility corpus and conformance harness; contributor workflow;
generic coding-agent examples over the existing CLI and Agent Query
API; and both Windows artifacts carrying the full compatibility
payload. Product decision recorded in the v0.9 milestone prompt: the
roadmap bullet "Reference MCP adapter over the stable Agent Query API"
is **removed** from v0.9 — no MCP server, adapter, transport, tool
mapping, SDK, or configuration may be introduced.

**Status: the mandatory preflight gate exposed the same debt chain that
blocked v0.4, v0.5, v0.6, v0.7, and v0.8 — now six milestones deep.
v0.9 implementation is BLOCKED until v0.3 is completed and v0.4, v0.5,
v0.6, v0.7, and v0.8 are each implemented and accepted. Five of the
seven majors named by v0.9's own stop rule are absent: bounded
schema/rule validation (no JSON Schema validator exists in the tree),
safe archive publication (no archive extraction/validation path exists
anywhere — v0.3 W7 was never built), stable Agent operation schemas
(no Agent Query Protocol exists — v0.5 never implemented; 0 of the 28
post-v0.8 operations exist), disclosure parity (v0.3 W6
redaction/disclosure was never built), and byte-equivalent packaging
(`tools/logscope-setup` does not exist; only the portable ZIP path).
The two present majors — deterministic canonical import and lossless
profile provenance — hold at the v0.1 contract level only. No v0.9
registry, pack, DSL, compiler, profile, recipe, template, corpus,
harness, UI, CLI, or packaging code was written in this session:
freezing extension-pack, template, conformance, and provenance
contracts against today's tree would bind them to guessed shapes of
the unbuilt v0.3 report/redaction/bundle contracts, v0.4 analysis
identities, v0.5 Agent protocol, v0.6 metric profile model, v0.7
session/rotation substrate, and v0.8 dashboard/report definitions —
exactly the incompatible parallel system the stop rule forbids.**

## Preflight decision (per milestone rules)

The v0.9 milestone rules distinguish narrow gaps ("fix narrow
regressions or small missing prerequisites when they are clearly
required by v0.9 and do not redesign completed import, query,
investigation, telemetry, Agent, or packaging foundations") from major
prerequisites ("If a major prerequisite such as deterministic canonical
import, lossless profile provenance, bounded schema/rule validation,
safe archive publication, stable Agent operation schemas, disclosure
parity, or byte-equivalent packaging is absent, **stop before freezing
an incompatible extension contract**"), and additionally forbid
silently reimplementing v0.0 through v0.8, creating a separate
canonical model/query language/dashboard engine/report renderer/
redaction engine/Agent operation list for extensions, or turning
compiled-in parser functions into opaque pseudo-declarative names.

The gaps found are not narrow regressions. Directly from the stop
rule's named list: **bounded schema/rule validation is absent** (P19 —
no JSON Schema validator exists), **safe archive publication is
absent** (P18 — no archive extraction path exists anywhere), **stable
Agent operation schemas are absent** (P12–P15 — all of v0.5),
**disclosure parity is absent** (P10/P11 — v0.3 W6 never built), and
**byte-equivalent packaging is absent** (P22 — one artifact). Around
them sit five unimplemented milestones plus seven unstarted v0.3 work
packages:

| Missing capability | Milestone debt | v0.9 work it blocks |
|---|---|---|
| Reports, shared redaction/disclosure projection, portable `.logscope-case` bundles (incl. the safe archive container), evidence/timeline UX, 5M benchmarks, release prep incl. `tools/logscope-setup` | v0.3 W3–W9 + W-R | pack container safety (WP1) reuses the bundle archive path; case-bundle pack-dependency snapshots (WP2); report templates (WP8); disclosure-aware provenance display; packaging gates; corpus baselines |
| Deterministic analysis: patterns, comparisons, correlation engine, findings, confidence classes, semantic fingerprints, cache invalidation | all of v0.4 | detection-score/fingerprint conventions (WP4); dashboard/finding-adjacent template semantics; cache-invalidation contracts for compiled plans and detection caches (WP12) |
| Agent Query Protocol v1alpha1 (registry, 28 operations, schemas, capabilities, cursors, disclosure, budgets, tokens, audit, CLI `logscope-cli.exe`, loopback HTTP) + cross-process workspace locking | all of v0.5 | generic coding-agent examples (WP11); CLI command surface v0.9 extends with pack/conformance commands; read-only registry exposure rules; concurrent desktop+CLI registry access (WP12) |
| Canonical metric pipeline, metric Import Profiles, Metric Query Definition v1, Metrics Explorer, five `metric.*` Agent operations | all of v0.6 | one-registry coexistence of log and metric profiles (WP1/P7); Prometheus-bridge recipe assertions (WP9); metric panels in dashboard templates (WP8) |

compiler) needs the JSON Schema validator decision and the disclosure

in step with the registry it lives in; WP8 (templates) instantiates

harness) binds golden/conformance contracts to unbuilt provenance and
baselines; WP11 (contributor workflow, CLI, agent examples) documents
a CLI and Agent API that do not exist; WP12 (migration/concurrency/
performance) migrates v0.8 workspaces that cannot exist and benchmarks

requires the Linux CI leg and the second Windows artifact. The correct
action is to stop, keep the repository valid and green, record this
